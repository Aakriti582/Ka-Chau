A note on precision modes

Ka Chau has three sharing precisions, and they are not degrees of the same thing — they change what data leaves the server at all. exact returns coordinates plus a metre-level distance. approx returns a distance rounded to roughly 100 m and no coordinates. proximity_only, which is the default, returns no number and no coordinates whatsoever — only a boolean and a bucket ("Very close", "Within 1 km", "Within 2 km"). The distinction is enforced in NearbyViewSet.list, where the coordinates are simply never serialised for the lower two modes; a client cannot leak what it was never sent. This has already been flattened twice by accident — once by a PATCH endpoint that bypassed the create-time validator, and once by a UI badge labelling proximity_only as "approx" — so treat any code that touches precision as worth a second look.
